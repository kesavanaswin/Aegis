# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately. If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security** tab to submit a report. Otherwise, contact the repository maintainers privately through GitHub.

Please do not publish vulnerability details in a public issue or discussion until the maintainers have had a reasonable opportunity to investigate and address the report.

When reporting, include the affected version or commit, a description of the issue, steps to reproduce it in a system you own or are authorized to test, and any relevant logs or screenshots. Do not include real credentials, personal data, or sensitive production information.

## Authorized use

Only test this project and its integrations on systems you own or have explicit permission to assess. Follow the repository's license and applicable laws. This security policy is guidance for reporting vulnerabilities; it does not change the project's license or grant permission to test third-party systems.

## Response

The maintainers will review reports as time permits. Please allow time for investigation and coordinated remediation before public disclosure.
